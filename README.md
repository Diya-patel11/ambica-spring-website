# Ambica Spring – Business Website

## Description
This project is a responsive business website developed for Ambica Spring, a spring manufacturing company. The website provides company information, services, and contact details to help customers learn about the business and connect easily.

## Features
- Responsive website design
- Company information and services
- Contact section
- Clean and simple user interface

## Technologies Used
- HTML
- CSS
- JavaScript

## Author
Developed as a real-world web development project for a family manufacturing business.
